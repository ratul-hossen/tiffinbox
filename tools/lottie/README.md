# TiffinBox motion graphics (Lottie)

The app's animations in `app/src/main/res/raw/lottie_*.json` are **original**
flat vector designs generated by `make_lottie.py` (no third-party assets, so
no licensing questions). 512x512 @ 30fps, brand colours.

| file | where it plays | loop? |
|---|---|---|
| `lottie_splash_ripple` | Splash, behind the logo | once |
| `lottie_success_check` | Checkout "order placed" dialog; Order tracking when delivered | once |
| `lottie_star_burst` | Rewards, behind the rank badge | once |
| `lottie_cooking_pot` | Order tracking while Cooking | loop |
| `lottie_delivery_pin` | Order tracking while Out for delivery | loop |
| `lottie_hourglass` | Order tracking while Placed/Accepted; chef "waiting for approval" | loop |
| `lottie_empty_bowl` | Every empty state (cart, orders, favorites, search, home) | loop |

Regenerate / preview:

```bash
python -m venv venv && venv/bin/pip install "lottie[PNG]" cairosvg pillow
venv/bin/python make_lottie.py out/            # writes the .json files
venv/bin/python render_lottie.py out/ .        # contact sheet: lottie_sheet.png
cp out/success_check.json ../../app/src/main/res/raw/lottie_success_check.json  # etc.
```

Designer-made Lottie files (After Effects + Bodymovin, or LottieFiles) can
replace any of these 1:1 - keep the same `lottie_*.json` name.
